# Конструктор чек-листов по кибергигиене

No-code / AI прототип интерактивного конструктора чек-листов для преподавателей и HR.

## Описание проекта

Преподаватели и HR-специалисты могут собирать интерактивные обучающие чек-листы из блоков (текст, изображение, вопрос), публиковать их по ссылке и получать результат прохождения без регистрации.

## Ссылка на прототип

**Живой прототип:** https://cyper-checklist-constructor.lovable.app

## Технологии

- Платформа: Lovable.dev (AI no-code)
- Drag-and-drop
- Хранение структуры в JSON
- XSS-защита через DOMPurify
- Хостинг: Lovable

## Структура репозитория

- `Docs/` — устав, ТЗ, протоколы
- `Design/` — схема архитектуры
- `Prototype/` — ссылка на прототип

## Как открыть

Перейдите по ссылке на прототип выше. Регистрация не требуется.
